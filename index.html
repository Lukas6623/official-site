Overview

One console for your Linux servers.

ServerGuard runs on Windows and manages Linux servers over SSH. Detection and protection run as background services on the server itself, so they keep working whether or not your computer is switched on.

  • Windows client, Linux servers — connect to any Linux server reachable over SSH.
  • Protection runs on the server — modules are installed on Linux and operate independently of the client.
  • Starts automatically — modules integrate with the Linux system manager and can restart after a reboot.
  • Layered by design — each module handles its own class of events instead of one catch-all rule.

Protection modules

Built from focused, layered modules.

Every module targets one class of events and is managed from the same SSH connection.

Brute-force Protection

The Security module watches SSH authentication, counts failed logins per source and automatically restricts addresses that pass the configured threshold.

  • Counts failed SSH authentication attempts per source
  • Applies a firewall block when the threshold is reached
  • Supports temporary and permanent blocking and a whitelist

Quick start

Install, connect, enable protection.

The workflow is the same for every server: install the Windows application, connect over SSH, then enable the modules you need.

01

Install ServerGuard

Download the installer, run the setup wizard on your Windows computer and start ServerGuard.

02

Connect over SSH

Enter the server IP address, SSH port, username and password — or another supported authentication method — and connect.

03

Enable protection

Open a module from the terminal and enable the protection you need directly on the server.

ServerGuard terminal root@server
security brute-force protection
hardening SSH configuration hardening
sshkeys SSH key monitoring
fileguard file integrity monitoring
telegram notifications and remote control

Configuration is stored on the server, so protection continues while the client is closed. See the testing guide for a step-by-step walkthrough of each module.

Security model

Keep unwanted access away.

ServerGuard monitors SSH activity and gives you the tools to respond to suspicious access attempts without reading logs by hand.

  • SSH activity monitoring
  • Failed login detection
  • Automatic IP blocking
  • IP whitelist management
  • SSH key change monitoring
  • Telegram security notifications

Protected network

Protection where the servers are.

ServerGuard keeps the management interface separate from the protection itself. The Windows client controls the modules, while detection and response run on the Linux server.

  • Modules run on the Linux server, not on the Windows client.
  • Protection keeps running while your computer is offline.
  • Services start again together with the system.
  • Each module reports its own events back to ServerGuard.
