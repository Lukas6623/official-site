01 / INTRODUCTION

ServerGuard Testing Guide

This documentation provides a step-by-step guide for testing ServerGuard on a Linux server.

🛡

About ServerGuard

ServerGuard is a Windows application designed to manage and protect Linux servers through SSH. It provides security modules for monitoring, protection and server administration.

Creating a Telegram bot with BotFather

Before ServerGuard can send notifications, you need a Telegram bot and its token. The token is created by the official Telegram bot @BotFather.

01

Open BotFather

In Telegram, search for @BotFather (the account with the blue verified badge), open the chat and press Start or send /start. BotFather will show the list of available commands.

02

Create a new bot

Send /newbot. BotFather will ask for two things:

1. A name for the bot (displayed in chats), for example Test Bot.
2. A username that must end with bot, for example server_guard_test_bot. The username must be unique.

03

Copy the bot token

In the final message, BotFather shows the token under the line “Use this token to access the HTTP API”. It looks like this:

123456789:ABCdefGhIJKlmNoPQRstuVWxyZ

Tap or select the token and copy it. If you lose the message, send /mybots, choose your bot and open API Token, or send /token.

04

Paste the token into ServerGuard

Open the Telegram Bot module in ServerGuard, choose 1. Install / configure bot and paste the token when ServerGuard asks for it. Then use 2. Generate verification code and send the code to your bot in Telegram to connect your account.

Important

Never publish the Telegram bot token or other authentication credentials in screenshots, public repositories or documentation. Anyone who has the token can control your bot. If the token was exposed, send /revoke to BotFather to get a new one and update it in ServerGuard.

11 / TESTING

Recommended testing procedure

The following sequence can be used as a structured evaluation of ServerGuard.

01

Connect

Connect ServerGuard to the provided Linux test server through SSH.

02

Check terminal

Run help, pwd and ls and verify that terminal commands work correctly.

03

Test Security

Install or enable the Security module, start protection and check its status.

04

Check logs

Review module logs and verify that security events are recorded.

05

Test Telegram

Install/configure the Telegram Bot, generate the verification code and verify notifications.

06

Test SSH Key Guard

Run a scan, create a baseline and review the generated audit information.

07

Test other modules

Review SSH Hardening and FileGuard according to the available test scenario.

08

Review results

Check statuses, logs, generated events and Telegram notifications.

12 / TROUBLESHOOTING

Troubleshooting

If something does not work as expected, check the following areas first.

ServerGuard cannot connect to the server
Check the server IP address, SSH port, username and authentication credentials. Also verify that the SSH service is running and accessible from the Windows computer.
A module is not installed
Open the corresponding module and use its installation/configuration option. After installation, check the module status.
A service is not running
Use the module's status and log options. If available, restart the service and review the resulting logs.
Telegram Bot is inactive
Check whether the bot is installed, configured and started. Then check its status and logs.
Where can I find more information?
Visit the ServerGuard website or the project's GitHub page for additional information and development updates.
