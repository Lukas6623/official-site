ServerGuard Documentation

ServerGuard is a Windows desktop application for managing, monitoring and protecting Linux servers over SSH. It combines security tools, best practices and a convenient interface in a single solution.

Download ServerGuard Security module

Security-first server management

Harden your servers, prevent attacks and manage configuration with ease.

  • Windows client
  • Linux server
  • SSH management

Protection runs on the server

Modules are installed on the Linux server and operate independently of the client, so detection and response keep running whether or not your computer is switched on.

Managed over one SSH connection

Connect once over SSH, then open and manage every module from the ServerGuard terminal — Security, Hardening, key and file monitoring and Telegram.

Module / SSH Hardening

Review and apply an SSH security policy

SSH Hardening reviews and manages security-related OpenSSH configuration. The policy is written to a separate configuration fragment, validated and backed up before it is applied.

  • Applies a controlled policy without rewriting the administrator's configuration
  • Validates the configuration and reloads the SSH service
  • Creates a backup and supports restoration

Protection modules

Each module targets one class of events and is managed from the same SSH connection.

Security SSH brute-force detection with automatic restrictions. Read module → SSH Hardening Review and apply a controlled OpenSSH security policy. Read module → SSH Key Guard Monitor authorized_keys and raise events on changes. Read module → FileGuard File integrity monitoring with baselines, scans and logs. Read module → Telegram Bot Security notifications and remote management on Telegram. Read module →

Installing ServerGuard on Linux

ServerGuard is also available as a Linux desktop application. Download version 1.1.8 for x86_64 / AMD64 from the Linux downloads page. Choose a DEB, RPM or TAR.ZST package for your distribution.

Before running an installation command, open a terminal and change to the directory containing the downloaded package.

Ubuntu / Debian — DEB

Ubuntu / Debian
sudo apt install ./serverguard_1.1.8-1_amd64.deb

Fedora / RHEL — RPM

Fedora / RHEL
sudo dnf install ./serverguard-1.1.8-1.x86_64.rpm

Arch Linux — TAR.ZST

Arch Linux
sudo pacman -U ./serverguard-1.1.8-1-x86_64.pkg.tar.zst

12 / TROUBLESHOOTING

Troubleshooting

If something does not work as expected, check the following areas first.

ServerGuard cannot connect to the server
Check the server IP address, SSH port, username and authentication credentials. Also verify that the SSH service is running and accessible from the Windows computer.
A module is not installed
Open the corresponding module and use its installation/configuration option. After installation, check the module status.
A service is not running
Use the module's status and log options. If available, restart the service and review the resulting logs.
Telegram Bot is inactive
Check whether the bot is installed, configured and started. Then check its status and logs.
